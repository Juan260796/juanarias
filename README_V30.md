# JUAN CUENTAS v30

Corrección de codificación de emojis en mensajes enviados a WhatsApp.

- Los emojis usados en textos de WhatsApp se construyen con escapes Unicode seguros.
- Se centraliza la creación de enlaces de WhatsApp y se normaliza el texto antes de codificarlo.
- Corrige promociones, mensajes de vencimiento, entregas de cuentas y garantías.
- No requiere migración SQL.
