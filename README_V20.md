# JUAN CUENTAS v20

Corrección visual del panel administrador:

- El menú lateral ahora tiene scroll vertical propio e independiente.
- Al colocar el puntero sobre el menú y usar la rueda del mouse, se desplaza el menú izquierdo y no el contenido derecho.
- En móvil, el menú lateral también se puede deslizar verticalmente con el dedo.
- El botón Salir permanece accesible al final del menú.
- No requiere cambios SQL ni nuevas variables de entorno.
