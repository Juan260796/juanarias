# JUAN CUENTAS v35

Cambios principales:
- Cuentas activas y vencidas: botón Editar para corregir fecha de inicio, servicio y perfil/cupo.
- Al cambiar fecha de inicio o servicio, la fecha final se recalcula automáticamente usando la duración correspondiente.
- Si el pedido usa una cuenta de stock compartida, no permite cambiarlo a un servicio incompatible con esa cuenta para evitar dañar otras entregas.
- El perfil/cupo solo se puede cambiar si está libre.
- Selección múltiple para borrar pedidos, clientes, servicios, promociones, proveedores y cuentas de inventario.
- Botones Seleccionar todos / Borrar seleccionados / Cancelar selección.
- Conserva la sincronización con Google Sheets de clientes y pedidos JU.

No requiere SQL nuevo.
